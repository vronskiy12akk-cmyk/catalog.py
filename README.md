# 📚 Book Catalog (ISBN) — управляй своей библиотекой

> «Каждая книга имеет свой номер — каталог знает его»

**Book Catalog (ISBN)** — это набор консольных приложений для ведения каталога книг с использованием ISBN-кодов.  
Программа позволяет добавлять, искать, удалять и редактировать книги, автоматически проверяя валидность ISBN-10 и ISBN-13.

## 🚀 Особенности
- 📖 Добавление книг с полями: ISBN, название, автор, год издания, издательство.
- ✅ Автоматическая проверка контрольной суммы ISBN-10 и ISBN-13.
- 🔍 Поиск по ISBN, названию или автору.
- 🗑️ Удаление и редактирование записей.
- 📋 Вывод всего каталога в виде таблицы.
- 💾 Автосохранение в JSON-файл (`books.json`).
- 🎨 Цветной вывод в терминале.
- 📊 Статистика: общее количество книг, количество по авторам, годам.

## 🛠️ Установка и запуск

Для каждого языка — минимальные зависимости (в основном стандартные библиотеки).

| Язык       | Зависимости                          | Команда запуска                         |
|------------|--------------------------------------|-----------------------------------------|
| Python     | стандартная библиотека               | `python catalog.py`                     |
| Go         | стандартная библиотека               | `go run catalog.go`                     |
| JavaScript | Node.js, `fs`, `readline`            | `node catalog.js`                       |
| Java       | стандартная библиотека               | `javac catalog.java && java catalog`    |
| C#         | .NET (или mono)                      | `dotnet run`                            |
| Rust       | `serde`, `serde_json`, `chrono`      | `cargo run`                             |
| Ruby       | `json`, `date` (стандартные)         | `ruby catalog.rb`                       |
| PHP        | стандартная библиотека               | `php catalog.php`                       |
